# Ridha Rafeeque — Premium Website Redesign

Open `index.html` in a browser to preview.

## Existing images
The redesign is structured to reuse the current site's images. Because the live site's image files were not available for direct packaging in this environment, image slots are included for:
- `assets/hero.jpg`
- `assets/profile.jpg`

Replace those files with the corresponding existing images from ridharafeeque.com.
